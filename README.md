# Landing page demonstrativa — Marina Duarte

Site estático em HTML, CSS e JavaScript. “Marina Duarte” e o endereço `contato@example.invalid` são fictícios. Formação, cursos, serviços e demais textos profissionais são exemplos e devem ser conferidos e substituídos antes de publicar.

## Visualizar

Abra `index.html` no navegador ou sirva a pasta com um servidor estático.

## Identidade visual

O layout usa um monograma e elementos gráficos no lugar de fotografias.
